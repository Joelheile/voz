# {{name}}

A [Voz](https://github.com/Joelheile/voz) extension. Say "say hello" at the end of a dictation and Voz shows the greeting from its settings.

## Install

```
voz install {{name}}
```

## Develop

```
voz dev .
```

Voz loads the extension, reloads it on save and prints its logs. The API is in `voz.d.ts`.

## Publish

```
npm publish
```

The `voz-package` keyword in `package.json` lists it on the Extensions page in Voz.
