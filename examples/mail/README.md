# voz-mail

Dictate in Mail or Outlook and Voz formats the text as an email: greeting, short paragraphs, sign-off.

```
voz install npm:voz-mail
```

Add your own style in `~/.voz/settings.json`:

```json
{
  "config": {
    "voz-mail": { "style": "Start with \"Hi\" and end with \"Best, Joel\"." }
  }
}
```
