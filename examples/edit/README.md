# voz-edit

Change text by saying how. Dictate, then say "edit shorter" or "edit more formal", and Voz changes what you just said.

```
voz install voz-edit
```

- **Say "edit …":** changes the selection. With nothing selected, it changes your last dictation if it is still in the field, or else the whole field. Say "edit" again to keep refining the result.
- **Select text and tap right Option:** opens a card where you type what to change, or pick Shorter or Clearer. Leave it empty to fix mistakes only. The card comes back after each edit, so you can keep changing the text until you close it. With nothing selected, right Option runs Reply.

The notch shows that Voz is editing. Press Esc or click the X to stop. The text stays as it is until the edit is ready. If you type in the meantime, the edit opens in a note instead. Press Cmd+Z to undo an edit.

Edit writes with the model you pick the first time you tap right Option, or later under Settings > AI model. Apple's runs on your Mac. With ChatGPT or Claude, Voz sends the field's text and the app name to OpenAI or Anthropic only when you edit. Password fields are never read. If you start real sentences with "edit", pick another phrase in the settings.
